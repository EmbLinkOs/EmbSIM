# Contributing

Read the specification and architecture before changing model contracts.
Run `make test`. Add behavioral tests for new semantics, including failure cases.
Document component provenance, units, operating range and omissions. Keep GUI
code free of simulation behavior. Do not silently change schema or ABI versions.

Never commit credentials, generated binaries, or vendor packs without a confirmed
redistribution license. Preserve upstream licenses and notices on reused code.

For this project, commits and PRs must use the repository owner's configured
identity. Do not add `Co-authored-by` trailers or assistant authorship. Check Git
identity before committing; do not invent another person's identity.
